# dsh-TUI 0.10.2-async23.5

基于上游 0.10.2，基础提交 `8e1931e7bbd376dc8838d74f2fe24f052012542c`，保留个人版的 Recap 紧凑布局、回到底部按钮开关和 GitHub Release 更新来源。

本版替代 `0.10.2-async23.4`，将发布范围收回到待办快捷键修复。相对于 `0.10.2-async23.3`，只增加下列修复及其文档、回归和发布校验；输入区布局与状态栏默认内容保持 `async23.3` 的行为。

- 修复 macOS 待办面板把折叠快捷键误显示为 `⌘Q` 的问题。默认提示为 `Ctrl+Q`（Control+Q）；Ghostty 的 Command+Q 仍由终端处理退出。
- 待办面板和 `?` 帮助菜单都从实际快捷键配置生成提示；在 `/settings` 改键、配置多个按键或恢复默认值时，提示同步更新。
- 同步双语快捷键说明，并将待办快捷键回归加入发布工作流。

下载 `install.mjs` 后运行 `node install.mjs`。需要 Node.js ^22.19 或 >=24、npm、pnpm 和官方 dsh。安装沿用现有 dsh-tui profile；启动命令为 `dsh-tui` 或 `dst`。已运行的 dsh 需要退出后重新启动。

发布资产：`dsh-tui.tgz`（编译插件）、`install.mjs`（版本固定的安装脚本）、`SHA256SUMS`。DSH 核心仍使用官方运行时，本 Release 不提供独立二进制。

验证：TypeScript 编译、全部 `verify:build` 门禁和发布下载/校验回归通过。72 项待办快捷键断言覆盖中英文、全屏 120 列与 inline 60 列、默认按键、任务运行中折叠且不中断、帮助菜单、自定义按键与恢复默认值；待办投影与鼠标折叠、问卷布局、工具卡、状态栏、Recap 和回底按钮回归通过。
