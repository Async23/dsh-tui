# dsh-TUI 0.10.2-async23.6

基于上游 0.10.2，基础提交 `8e1931e7bbd376dc8838d74f2fe24f052012542c`，保留个人版的 Recap 紧凑布局、回到底部按钮开关、待办快捷键修复和 GitHub Release 更新来源。

修复 `0.10.2-async23.5` 默认显示上下文彩色图例的问题，恢复空闲时的完整用量明细。

- 默认显示占用率、已用/总容量、剩余容量与分类 token 数，例如 `1.3% · 12.9k/1m · free 987.1k · sys 1.4k · pr 2 · ast 230 · th 339 · tl 0`。
- 悬停上下文进度条时显示彩色图例，移开后恢复默认明细；悬停其他状态字段时仍显示对应详情。
- 执行提示、选择提示和已启用的活动摘要继续优先显示，结束后恢复默认明细，底栏高度不变。

下载本 Release 的 `install.mjs` 后执行 `node install.mjs`，校验通过后同时更新现有 dsh-tui profile 和全局启动器。也可使用已有个人版的 `dsh-tui update` 或 `/update`。需要 Node.js ^22.19 或 >=24、npm、pnpm 和官方 dsh；启动命令为 `dsh-tui` 或 `dst`。通过安装脚本更新后，已运行的空闲会话执行 `/restart` 即可恢复同一会话并加载新代码。

发布资产包括 `dsh-tui.tgz`（编译插件）、`install.mjs`（固定安装本版本的脚本）和 `SHA256SUMS`。DSH 核心仍使用官方运行时。

验证：`pnpm build` 的 TypeScript 编译和全部构建检查通过；99 项悬停与默认底栏断言、15 项发布下载与校验断言，以及问卷交互、问卷布局和工具卡回归通过。编译后的底栏在 fullscreen 和 inline 两种模式、120/80/40 列宽度下均验证了默认用量明细、悬停与执行提示优先级、恢复显示及行高稳定性。
