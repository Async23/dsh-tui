# dsh-TUI 0.10.2-async23.7

基于上游 0.10.2，基础提交 `8e1931e7bbd376dc8838d74f2fe24f052012542c`，保留个人版的 Recap 紧凑布局、回到底部按钮开关、待办快捷键修复和 GitHub Release 更新来源。

恢复输入框上方的紧凑布局：没有通知时不再保留一整行空白，让正文多显示一行。

- 输入框上方只在通知可见时留出一行，通知消失后立即收回。
- 通知消失与多行草稿清空都按实际高度收缩重绘，避免普通终端模式留下旧行或错位。
- 保留默认上下文用量明细、Recap 紧凑布局、回到底部按钮开关和待办快捷键修复。
- 新增真实 Chat 渲染回归，覆盖全屏与普通终端模式、120/80/40 列宽度、通知出现/替换/消失，以及多行输入收缩；接入 CI 与发布检查。

下载本 Release 的 `install.mjs` 后执行 `node install.mjs`，校验通过后同时更新现有 dsh-tui profile 和全局启动器。也可使用已有个人版的 `dsh-tui update` 或 `/update`。需要 Node.js ^22.19 或 >=24、npm、pnpm 和官方 dsh；启动命令为 `dsh-tui` 或 `dst`。通过安装脚本更新后，已运行的空闲会话执行 `/restart` 即可恢复同一会话并加载新代码。

发布资产包括 `dsh-tui.tgz`（编译插件）、`install.mjs`（固定安装本版本的脚本）和 `SHA256SUMS`。DSH 核心仍使用官方运行时。

验证：`pnpm build` 的 TypeScript 编译和全部构建检查通过；新增的 66 项输入区布局断言、15 项发布下载与校验断言，以及问卷交互、问卷布局、工具卡、上下文明细、Recap、待办快捷键和回到底部回归通过。输入区检查覆盖 fullscreen/inline 两种模式和 120/80/40 列宽度。
